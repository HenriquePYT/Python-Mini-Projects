
# Python Mini-Projects 🚀

A collection of custom command-line interface (CLI) applications built entirely from scratch to master core Python programming, data structures, loops, and rigorous user input validation.

---

## 🛠️ Projects Included

### 1. Contact Book CLI (`CLI.py`)
* **Description:** A terminal-based contact management system.
* **Features:**
  * Add contacts with name, age, and phone number[cite: 2].
  * Robust input validation loops to ensure fields are never left empty[cite: 2].
  * Search functionality by contact name[cite: 2].
  * Clean list-of-dictionaries architecture (`contacts = []`)[cite: 2].

### 2. Digital Danuza's Pizza System (`danuza pizza basic project 1 file.py`)
* **Description:** An interactive ordering system tailored for a local pizzeria context[cite: 3].
* **Features:**
  * Dynamic menu selection using modern Python control flow (`match/case`)[cite: 3].
  * Real-time price calculation, item counts, and fixed delivery fee integration[cite: 3].
  * Formatted output summaries (`{total_price:.2f}`) and customer validation loops[cite: 3].
